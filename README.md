# phone-calculator

A clean, minimal calculator for iOS and Android built with React Native and Expo.
Designed with a dark interface and smooth interactions in mind.

## Features

- Addition, subtraction, multiplication and division
- Chained calculations with live expression preview
- Percentage, decimal input and sign toggle
- Backspace and full clear
- Responsive layout across all screen sizes

## Getting Started

Make sure you have [Node.js](https://nodejs.org) and 
[Expo Go](https://expo.dev/go) installed.

```bash
npx create-expo-app CalculatorModern
cd CalculatorModern
```

Replace the generated `App.js` with the one from this repository, then:

```bash
npx expo start
```

Scan the QR code with Expo Go on your device.
